# Root Cause Analysis

The clean-room lifecycle had authoritative Stage 02 records but no complete application contract between author identity, the real Intake, required responses, and the operating-center surfaces. Completeness could not be derived from durable response evidence because no governed response entity or command existed.

The prior display path also allowed legacy projections to dominate the human-facing state. Separately, the transition plug-in persisted `JM1-Dev` as a literal value, so managed promotion could carry an incorrect label into UAT.

The remediation adds a bounded V2 adapter: browser input is limited to answer values and save/submit intent; all identity and lifecycle keys are supplied and validated server-side. Environment identity is now resolved from an active Dataverse authority record.

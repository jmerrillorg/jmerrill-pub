# Microsoft Change Notice

Microsoft documentation reviewed on 2026-07-30 states that Azure Copilot is available to all users in a tenant by default unless a Global Administrator limits access through Azure RBAC. Microsoft also documents that Agents preview access can be requested at the tenant level, that access requests may already have been made automatically for tenants, and that new preview agent capabilities become available automatically after approval.

Relevant Microsoft sources:

- https://learn.microsoft.com/en-us/azure/copilot/manage-access
- https://learn.microsoft.com/en-us/azure/copilot/manage-agents-preview
- https://learn.microsoft.com/en-us/azure/copilot/agents-preview
- https://learn.microsoft.com/en-us/training/modules/introduction-azure-copilot-agents/

The documented preview agent families are:

- Deployment Agent
- Migration Agent
- Observability Agent
- Optimization Agent
- Resiliency Agent
- Troubleshooting Agent

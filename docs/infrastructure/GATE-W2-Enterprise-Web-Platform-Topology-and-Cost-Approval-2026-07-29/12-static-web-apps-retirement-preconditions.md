No Static Web App may be retired until all applicable controls pass:

- Replacement production health
- DNS validation
- TLS validation
- Route parity
- Form/API/auth validation where applicable
- Monitoring and alerts
- Rollback proof
- Evidence package
- Deployment history retained
- Cost confirmation
- Jackie approval
- Retirement event logged

Current SWAs remain active. Retirement is separately authorized by property or wave.

# Jackie-title downstream recovery boundaries

This change preserves completed intake runs and historical title state. It does
not enable editorial or broad stage workers, inference, author decisions or release.

Review replay now rechecks source-version, exact extracted word count, title echo
and advisory imprint authority before rendering a saved report. After inference,
the producer downloads and hashes the source again before publishing any receipt.
Both paths retain identity/scope/canon checks and reject source drift.

The separate Glory HELD6-to7 adapter is prepared in gloryNextAssessmentRecovery.js.
It has no timer binding. The authenticated EXECUTE_NEXT_ASSESSMENT route defaults
off and uses gloryNextAssessmentOwner to resolve new durable decision evidence, exact current payload,
release, source/canon, fresh native tariff/token budget and execution isolation.
The old consumed decision cannot be reused. One CAS claim preserves HELD6 and
its consumed-attempt history. Timeout, conflict or uncertain completion cannot
authorize automatic retry. Actual usage proof must bind the request and tariff.
No authority writer or new approval record is included in this change.

The existing authenticated recovery endpoint supports VERIFY_REVIEW_GUARDS,
a fixed effect-free synthetic probe with no caller-supplied fixture or title.
This demonstrates deployed denial paths, not real title downstream acceptance.

The owner binding and exact native budget reader are included; enabling or
writing new decision authority is not. Complete-year Long Watch historical byte
recovery remains separate. Do not label source completeness proved
from source tests or version sizes. TIL calendar alternatives remain retained;
no quarterly split or source promotion is implied.

# JMP Cover Production Specs

**Status:** CANON CACHE | Manual canon synchronized 2026-08-20

Production cover readiness depends on the selected product form and
distribution path. Cover Intelligence must not assume one universal cover
template for every title.

## Required Production Inputs

- product form;
- trim size;
- final page count;
- paper type;
- binding;
- spine width;
- barcode and ISBN;
- distribution path / template authority;
- file format;
- color mode;
- resolution;
- bleed and safe area;
- front / spine / back completeness.

## Readiness Rule

A cover file is not final-production ready until the exact production specs for
the selected format and distribution path have been applied and verified.

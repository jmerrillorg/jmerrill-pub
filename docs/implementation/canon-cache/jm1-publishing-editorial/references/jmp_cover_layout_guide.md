# JMP Cover Layout Guide

**Status:** CANON CACHE | Manual canon synchronized 2026-08-20

Cover layout review evaluates composition for the specific artifact state under
review: concept, full wrap, or final production cover.

## Concept Layout

- front-cover composition;
- title readability;
- subtitle hierarchy;
- author name placement;
- genre signal;
- visual focus.

## Full-Wrap Layout

- front / spine / back relationship;
- spine type fit;
- back-cover copy placement;
- barcode area;
- imprint / publisher placement;
- trim and bleed awareness;
- safe margins.

## Production Layout

- distribution-template compliance;
- exact trim, bleed, spine, and barcode requirements;
- export format and resolution;
- no placeholder production elements;
- final human approval state.

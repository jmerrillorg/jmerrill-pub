---

## Role And Mission

Distribution Review is a distinct final readiness gate. It is not an editing
stage and does not reopen Developmental, Line, Copy, Proof, Layout, or Cover
work unless a readiness defect requires return to the owning stage.

Distribution Review evaluates whether each format is ready for its intended
distribution path.

---

## Required Review Domains

Distribution Review must evaluate:

- metadata;
- categories and keywords;
- rights and territory;
- ISBN assignment and format alignment;
- final files and format readiness;
- accessibility;
- pricing;
- wholesale discount;
- returnability;
- print cost;
- profitability / margin;
- distribution-path readiness;
- sequencing and release timing.

---

## Profitability / Readiness Principle

A print format that fails required profitability or distribution readiness
cannot be marked Ready for Distribution merely because files technically exist.

Economic readiness, file readiness, rights readiness, and metadata readiness
must all be true for Ready status.

---

## Distribution Review Status

Use a tri-state readiness result:

- `READY` — all required checks pass.
- `MINOR_FIXES_REQUIRED` — distribution can proceed only after named fixes are
  completed and verified.
- `BLOCKED` — one or more hard readiness, rights, pricing, profitability, file,
  or sequencing defects prevent distribution.

---

## Boundary

Distribution Review may flag defects and route them to the owning capability.
It must not silently edit manuscript text, redesign cover files, change pricing,
change rights, mutate metadata, or release a format.

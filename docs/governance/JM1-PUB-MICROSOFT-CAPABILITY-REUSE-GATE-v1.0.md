# JM1 Publishing - Microsoft Capability Reuse Gate v1.0

> **JM1 Publishing — Microsoft Capability Reuse Gate v1.0**
> Effective 2026-08-07. Authority: Jackie Smith, Jr., President & CEO.
>
> No new Publishing build proceeds without a recorded disposition against already-licensed Microsoft capability: USE_AS_IS, CONFIGURE, EXTEND, CUSTOM_REQUIRED, or UNKNOWN. A disposition of UNKNOWN blocks the build until resolved.
>
> **Scope:** new builds only. This gate is **not retroactive.** The 11 replacement candidates identified in the Publishing Capability Register are logged for awareness and are **not** scheduled for remediation by this rule.
>
> **Origin:** the register found USE_AS_IS 0 across all nine parent capabilities — no Publishing capability uses licensed Microsoft capability as delivered. 11 replacement candidates, 7 unused or unproven licensed capabilities, 11 potential custom systems avoided.
>
> **Sunset condition:** this gate exists to remove more burden than it adds. If it becomes a form filled out rather than a question answered, it is to be retired rather than maintained.

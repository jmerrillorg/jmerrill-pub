# Validation Results

Scope: J Merrill Publishing Human Operating Layer v1.0
Date: 2026-08-06

## Scenario 1: New Employee

Result: PASS

A new Publishing Coordinator can:

- find today’s work through Run Today and Current Work;
- determine the next action on a title through the active title view;
- locate the correct agreement through Forms and Templates and the Current Authority Index;
- prepare an author review package through SOP 8 and SOP 9;
- know when Jackie approval is required through Decisions and Approvals.

Hold: Active title folders must continue to maintain plain-language current-state pages.

## Scenario 2: Jackie Unavailable for Two Weeks

Result: PASS

A trusted operator can:

- continue routine title work;
- communicate truthfully with authors;
- preserve financial and release obligations;
- stop correctly at executive boundaries;
- prepare a complete return briefing.

Hold: Operators must not treat absence playbook authority as approval for special terms, release exceptions, or automation thaw.

## Scenario 3: Current Document Lookup

Result: PASS

The operator can locate:

- current Hybrid agreement;
- current JM Signature agreement;
- author-copy policy;
- Operating Manual;
- current commercial catalog authority;
- current title closeout procedure.

## Scenario 4: Technical Isolation

Result: PASS

Ordinary work can be completed from the hub, Operating Manual, active title current-state page, and current templates without browsing architecture folders, session archives, code, technical evidence, implementation plans, or platform configuration.

## Scenario 5: Human-First Language

Result: PASS

The hub keeps primary procedures in business language. Specialist support references are limited to the final line of each SOP or curated reference pages.

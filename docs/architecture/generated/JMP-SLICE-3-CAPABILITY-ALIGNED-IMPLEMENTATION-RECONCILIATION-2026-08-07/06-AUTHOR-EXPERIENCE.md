# Author Experience Reconciliation

The existing author portal should not remain custom merely because it exists. Each surface must be tested against Microsoft-native options before runtime expansion.

| Author-facing area | Current state | Microsoft/custom assessment | Microsoft disposition | Proposed disposition |
| --- | --- | --- | --- | --- |
| Author Operating Center / Workspace | Existing web | Power Pages or Power Apps should be evaluated; existing web retained only if experience or data needs justify it. | EXTEND | RE-SCOPE |
| Agreement issuance | Agreement pipeline + SharePoint/Implementation HQ | Power Automate filing/status projection can reduce custom filing and manual version tracking. | CONFIGURE | KEEP |
| Onboarding | Existing web/onboarding routes | Power Apps/Power Pages + Dataverse + SharePoint can cover structured setup; Exchange for relationship messages. | CONFIGURE | RE-SCOPE |
| Review packages | SharePoint governed artifacts | SharePoint remains artifact authority; Power Automate can route reminders/approvals. | CONFIGURE | KEEP |
| Author decisions | Manual Jackie approval and author response | Power Automate Approvals/Adaptive Cards may cover routine decisions; sensitive decisions remain Jackie. | CONFIGURE | REPLACE_WITH_MICROSOFT |
| Communications | Exchange/ACS/custom dispatch | Exchange remains communication channel; custom dispatch only for governed package generation/evidence gaps. | EXTEND | RE-SCOPE |
| Status | Author-safe projection planned | Calculate/present from Dataverse title/edition state; persistence remains a decision. | EXTEND | RE-SCOPE |
| Downloads | SharePoint/governed artifacts | SharePoint links or Power Pages/Apps surface should avoid duplicating file storage. | CONFIGURE | RE-SCOPE |
| Correction handling | Correction Authorized design | Power Automate approvals + Dataverse audit before custom workflow. | CONFIGURE | REPLACE_WITH_MICROSOFT |
| Marketing profile | Existing author marketing profile route | Customer Voice/Forms/Dataverse should be assessed before custom profile expansion. | CONFIGURE | RE-SCOPE |
| Post-publication information | Manual/Operating Manual | Power BI/Power Apps/Power Pages projections can show statements/copies/status after authority. | EXTEND | DEFER |

## Additional Enforcement Rules

- Title summary state is calculated from title-level authority, edition/PF states, holds, cancellation, retirement, release readback, and author-review evidence.
- Content Freeze requires Editorial Master version evidence and must emit TITLE_CONTENT_FROZEN.
- Format & Title Lock must be verified before ISBN assignment and downstream date commitments.
- ISBN assignment before verified FTL must fail with TRANSITION_PRECONDITION_FAILED.
- CORRECTION_AUTHORIZED is required before returning approved, distribution-ready, submitted, or live work to production.
- Client-title automation remains frozen; any attempted automation activation fails with CLIENT_AUTOMATION_FROZEN.

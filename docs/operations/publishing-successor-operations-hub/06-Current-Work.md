# 06 Current Work

The current work view must be readable by a publishing operator without source IDs, back-office codes, or technical evidence.

## Active Work Source

Use the active title register and active title folders as the operating source for current work.

Current active title reference:

- `docs/operations/active/the-intentional-leader/CURRENT-STATE.md`

If additional active title folders exist, each should have a plain-language current state page before it becomes part of daily operations.

## Required View

Each active title should answer:

| Field | Required Plain-English Answer |
| --- | --- |
| Title | Book title or working title. |
| Author | Author name. |
| Current business stage | Intake, agreement, onboarding, editorial, production, distribution, release, correction, royalty, closeout, or hold. |
| Current editorial or production position | What has happened most recently. |
| Who owes the next action | Jackie, operator, author, vendor, distributor, counsel, finance support, or waiting. |
| Exact next action | The next concrete action. |
| Due or follow-up date | Date to act or check again. |
| Blocker | The reason movement is paused. |
| Priority | Today, this week, scheduled, waiting, or hold. |

## Operator Rule

If a title lacks an exact next action, treat that as a blocker. Do not rely on memory.

## What Not To Show

Do not include source IDs, hidden workflow names, correlation values, raw event names, or technical state codes in the human current-work view.

Those may remain in the support evidence layer.

This hub is the first place a successor, Publishing Coordinator, Operations Lead, or trusted operator should begin when running J Merrill Publishing.

The hub does not replace governed source documents. It points people to the current authority, explains what to do in plain English, and keeps ordinary publishing work away from technical archaeology.

## Operating Rule

Use this hub first. If this hub points to a current authority, use that authority. If it does not, pause the affected action and ask Jackie for the decision owner.

Do not search old folders, prior drafts, or generated evidence as a normal operating habit.

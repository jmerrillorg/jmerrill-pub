# 02 Run Today

Use this page at the beginning of each publishing workday.

## What To Look At First Today

1. Author responses received since the last work period.
2. Authors waiting on J Merrill Publishing.
3. Approvals waiting on Jackie.
4. Production tasks due today or overdue.
5. Distribution follow-ups and live-status checks.
6. Payment or royalty obligations due soon.
7. Exceptions, blockers, or promises with dates attached.

## Daily Operating View

Use the current active-title register listed in [Current Work](06-Current-Work.md). For each active title, confirm:

| Field | Plain-English Meaning |
| --- | --- |
| Title | The book being worked. |
| Author | The person or party owed communication. |
| Business stage | Intake, agreement, editorial, production, distribution, release, correction, royalty, or closeout. |
| Current position | What is happening now. |
| Next action owner | Jackie, operator, author, vendor, distributor, counsel, or finance support. |
| Exact next action | The smallest useful action that moves the title or protects the record. |
| Due or follow-up date | When to act or check again. |
| Blocker | What prevents movement. |
| Priority | Today, this week, scheduled, waiting, or hold. |

## What Requires Action Today

Act today when:

- an author is waiting on a promised response;
- Jackie owes an approval before work can continue;
- a production or distribution due date is near;
- a title has no clear next action;
- a payment, royalty, or author-copy obligation is due;
- a public listing appears wrong;
- a file defect could affect an author, vendor, or distributor.

## What Can Wait

Wait when:

- the title is already waiting on an author response;
- the next follow-up date has not arrived;
- the task is reference cleanup rather than active work;
- the work requires a decision that has not been made;
- the issue is cosmetic and does not affect author trust, release readiness, rights, payments, or public accuracy.

## What Requires Jackie

Pause and route to Jackie when the action concerns:

- accepting or declining a title;
- selecting or changing the Publishing Track;
- special terms or agreement exceptions;
- package benefit exceptions;
- Format & Title Lock;
- Correction Authorized;
- release exceptions;
- public-offer changes;
- client automation thaw;
- any decision that could change rights, royalties, price, scope, public promises, or author obligations.

## Routine Daily Checklist

- Review incoming author messages.
- Update the active-title next action.
- Check overdue items.
- Prepare routine packages already approved.
- File evidence for completed work.
- Draft status updates only when the message is standard and accurate.
- Escalate unclear authority.

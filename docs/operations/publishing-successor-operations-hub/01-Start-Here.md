# 01 Start Here

## What J Merrill Publishing Does

J Merrill Publishing helps authors move books from opportunity to finished publication through clear publishing decisions, careful editorial work, governed agreements, production preparation, distribution readiness, release confirmation, royalties where applicable, and post-release care.

## Mission and Operating Philosophy

The mission is to publish worthy books with care, clarity, and professional stewardship.

The operating philosophy is simple:

- authors should know where they stand;
- books should move only when the business basis is clear;
- current authority should be easy to find;
- evidence should outlast memory;
- uncertainty should pause the affected action instead of becoming improvisation.

## What This Hub Is For

This hub is the human entry point for running Publishing. It tells a new operator what to read, what to do today, which SOP applies, who approves decisions, and where current forms and templates live.

This hub is not a new filing system for every historical item. It is a guided operating layer above the existing governed sources.

## Current Frozen and Manual Boundaries

Client-title automation remains frozen.

Client-title production remains manual.

This hub does not authorize automatic title movement, automatic author communication, agreement changes, public-offer changes, financial changes, or new build work.

## How to Identify the Controlling Authority

Use the [Current Authority Index](Current-Authority-Index.md). If the item is listed as CURRENT, use the official location named there.

If two files appear current, pause and escalate before using either one.

If a file is in an old folder or generated evidence folder and is not listed as CURRENT, treat it as reference-only.

## How to Escalate Uncertainty

When authority is unclear:

- pause the affected action;
- preserve the current state;
- identify what decision is needed;
- ask Jackie or the named decision owner;
- do not create a workaround.

Systems needed:

- current publishing files;
- current active title register;
- approved agreement templates;
- author communication mailbox or approved communication channel;
- storage location used for title evidence and author deliverables;
- payment and royalty records only when assigned.

Do not change:

- agreement language;
- package benefits;
- title acceptance decisions;
- royalty terms;
- public offers;
- client-title automation status;
- production files without the approved source text.

Who approves decisions:

- Jackie approves publishing acceptance, track, special terms, release exceptions, correction authority, public-offer changes, and automation thaw.
- Operators may complete routine follow-up, evidence filing, checklist preparation, scheduling, and standard status updates under approved policy.

Where current work is found:

- Start with [Current Work](06-Current-Work.md).
- Use the active title register linked there.
- Do not treat archive folders as today’s work queue.

How to avoid stale files:

- Use this hub first.
- Check the status in the Current Authority Index.
- Avoid files marked draft, superseded, archive, generated, old, redline, clean copy, or backup unless the index points to them.

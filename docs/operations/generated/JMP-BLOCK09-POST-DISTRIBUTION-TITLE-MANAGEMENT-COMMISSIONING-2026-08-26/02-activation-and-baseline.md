# Activation And Published Title Baseline

Last Verified: 2026-08-26

## Activation Rule

TITLE_LIVE_AND_VERIFIED = TRUE -> TITLE_MANAGEMENT_ACTIVE.

Block 09 does not require LAUNCH_CYCLE_COMPLETE. Block 08 and Block 09 may overlap.

## Baseline

PUBLISHED_TITLE_BASELINE references:

- Work / title
- Edition
- Author relationship
- Governing contract/addendum
- Publication date
- Formats
- ISBNs / identifiers
- Release manifest
- Final publication assets
- Block 07 external channel IDs
- Verified live URLs
- Territory / pricing / wholesale-returnability
- Royalty rule version
- Fee rule version
- Release health
- Rights state

Immutable snapshots are used only where historical reproduction requires them; no duplicate canonical authority is created.

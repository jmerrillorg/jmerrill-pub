# Change Routing, Edition, And Format

Last Verified: 2026-08-26

## Post-Publication Change Classification

Supported classifications:

- METADATA_ONLY
- MINOR_PUBLICATION_CORRECTION
- PRODUCTION_CORRECTION
- MATERIAL_CONTENT_REVISION
- NEW_EDITION
- FORMAT_EXPANSION
- PRICE_TRADE_CHANGE
- RIGHTS_TERRITORY_CHANGE
- OTHER_GOVERNED_CHANGE

## Proportional Re-Entry

Metadata-only changes stay in Block 09 validation/channel update/live verification. Production corrections re-enter affected production/readiness/distribution controls. Material revisions re-enter Block 04 and downstream blocks. New formats re-enter Block 05, Block 06, Block 07, and Block 08 format launch as required.

## Edition Succession

New edition does not overwrite old edition. Prior sales, royalties, ISBNs, distribution history, marketing, URLs, files, contracts, and statements remain attached to the historical edition.

# Guards and Prevention

## Fail-Closed Conditions

The ISBN gate blocks assignment when:

- canonical title is missing;
- title ID is missing;
- author/contributor presentation is missing;
- imprint is missing;
- format is missing;
- edition is missing;
- rights holder is missing;
- publication status is missing;
- proposed publication date is missing;
- proposed ISBN is missing;
- proposed ISBN is not publisher-owned;
- duplicate canonical title records exist;
- title is test or synthetic;
- product is abandoned;
- ISBN is already assigned to a different product;
- product already has a different ISBN;
- a new edition attempts to reuse a prior edition ISBN.

## Non-Assignment Cases

Do not assign ISBNs to:

- author-review PDFs as separate products;
- test or synthetic titles;
- internal package artifacts;
- provisional formats not approved for publication;
- duplicate title records;
- abandoned production experiments;
- unchanged reprints that retain an existing ISBN.

## The Intentional Leader

The current Interior Layout author-review proof is not a final distribution-ready file. Its ISBN-pending status is permitted and does not block author review.

# Human-Event Evidence Precedence

Last verified: 2026-08-17T02:18:20.394Z

Evidence source: approved recovery instruction and read-only canonical project census.

The operating board applies this precedence order when raw system rows conflict:

1. Explicit real human decision tied to the exact project/artifact.
2. Certified communication/delivery evidence.
3. Artifact provenance plus approval.
4. Current governed project/business state.
5. Canonical Dataverse stage.
6. Historical or duplicate intake/stage records.

This pass does not delete Dataverse history. It prevents stale or duplicate rows from becoming Jackie-facing work when stronger human/business evidence proves a different current state.

# Event Contract

Events that should trigger reevaluation include intake submitted, manuscript received, classification completed, editorial review completed, author package decision, pricing locked, agreement generated/executed, payment received, Joined the Family, author approval, editorial job completed, artifact certified, production readiness changes, release events, and royalty/payee state changes.

Recovery events include failed workflow, retry window reached, Foundry capacity available, Stripe requirement update, portal entitlement update, relay health restored, and external integration recovery.

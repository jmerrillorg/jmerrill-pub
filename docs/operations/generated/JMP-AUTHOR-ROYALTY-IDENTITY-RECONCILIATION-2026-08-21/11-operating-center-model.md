# Publisher Operating Center Model

Last Verified: 2026-08-22T01:08:44.371Z
Evidence Source: attached Publisher Operating Center target addendum.

The royalty-payee migration/readiness view should show, at minimum:

- Author
- Author relationship
- Royalty payee system
- Bill.com legacy ID
- Stripe Connect account
- Identity reconciliation status
- Onboarding status
- Payouts enabled
- Requirements due
- Ready for royalties
- Last invite
- Last reminder
- Payout hold
- Exception
- Next action
- Waiting on

Sensitive banking, routing, SSN, TIN, and raw Stripe verification details must not be exposed in the operating view.

# Author Gate Alignment
ALIGNED — genuinely code-enforced, not merely documented. editorialAuthorGatePolicy.js's STAGE_TRANSITIONS + evaluateNextStageEligibility require a fully-approved, checksum-matched author gate on the upstream stage before a stage enters the execution queue (findActiveEditorialStages). No AI-finished-to-auto-advance path exists anywhere; the stage prompt itself states the invariant explicitly ("Model completion and QA are not author approval"). Gate approvals are only ever written from a real, parsed inbound author email reply (authorReviewResponseConsumer.js), never from model/QA completion.

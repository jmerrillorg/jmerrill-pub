# Author Presentation

Last verified: 2026-08-21T00:00:00Z

## Communication Rule

New-policy author-facing communication must present:

- cash price clearly;
- payment options clearly;
- disclosed payment-plan charge;
- early payoff available at any time;
- no early-payoff penalty;
- unearned future payment-plan charge waived.

## Prohibited Language

The new-policy communication must not describe the plan as a 4% transaction fee offer.

## Validation

Package acceptance communication tests confirm new financing terminology appears and the old 4% transaction-fee language does not appear for the new policy.

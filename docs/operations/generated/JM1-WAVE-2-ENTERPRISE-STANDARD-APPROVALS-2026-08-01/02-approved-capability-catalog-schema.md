# Approved Capability Catalog Schema

Status: APPROVED WITH AMENDMENTS

Required fields:

| Field | Purpose |
| --- | --- |
| capability_id | Stable enterprise capability identifier. |
| name | Human-readable capability name. |
| entity | Owning or consuming entity. |
| owner | Accountable owner. |
| business_purpose | Why the capability exists. |
| source_of_authority | Canon, ruling, ADR, standard, or contract source. |
| entitlement_state | Designed/Entitled evidence for licensed or authorized use. |
| configuration_state | Current configuration maturity. |
| activation_state | Whether operational activation exists. |
| validation_state | Validation evidence and date. |
| monitoring_state | Monitoring and alert coverage. |
| optimization_state | Optimization/readiness state. |
| system_of_record | Authoritative record system. |
| dependencies | Technical, human, legal, accounting, or vendor dependencies. |
| evidence | Canonical evidence package or record. |
| risk | Current operational or governance risk. |
| retirement_status | Active, candidate, deprecated, retired, merged, or provisional. |

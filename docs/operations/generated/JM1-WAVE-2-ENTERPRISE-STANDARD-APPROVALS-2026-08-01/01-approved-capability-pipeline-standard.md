# JM1 Enterprise Capability And Pipeline Standard v1.0 - Approved Wave 2 Form

Status: APPROVED WITH AMENDMENTS

## Maturity Vocabulary

Every material capability must be assessed using these states:

1. Designed
2. Entitled
3. Configured
4. Activated
5. Validated
6. Proven
7. Monitored
8. Optimized

Architecture, entitlement, configuration, activation, validation, production proof, monitoring, and optimization must not be collapsed into a single score.

## Pipeline Authority

J0-J8 remains the enterprise pipeline vocabulary for lifecycle movement, with evidence required at each gate before a capability is presented as active or proven.

## Boundary

Approval of this standard creates governance authority. It does not deploy systems, activate dormant capabilities, commission agents, change legal structures, or grant permissions.

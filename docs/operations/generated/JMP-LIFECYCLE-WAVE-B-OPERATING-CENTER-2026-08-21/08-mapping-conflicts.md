# 08 - Mapping Conflicts

Mapping dispositions:

- `CANONICAL_MAPPING_EXACT`
- `CANONICAL_MAPPING_CONTEXTUAL`
- `CANONICAL_MAPPING_CONFLICT`
- `CANONICAL_MAPPING_INCOMPLETE`

Conflict rule proven:

Legacy `EDITORIAL_REVIEW` for an active title does not map to a production substage unless Developmental, Line, or Copy context exists.

Incomplete rule proven:

Unknown legacy values produce `DATA_GAP` and `Resolve lifecycle mapping conflict`.

Title-name pollution prevention:

`Editorial Review - Final Proof in the Title` remains an Editorial Review conflict rather than being misread as Proofreading.

# 05 - Waiting / System Attention

Waiting On maps to canonical owners:

- Prospect
- Author
- JMP
- JMP/System
- External

System Attention remains separate and can surface:

- NONE
- AUTHOR_ACK_FAILED
- PAYMENT_EVENT_FAILED
- PROVIDER_BACKPRESSURE
- ARTIFACT_AUTHORITY_UNRESOLVED
- TRANSITION_CONFLICT
- LIFECYCLE_SPLIT_BRAIN
- RUNTIME_HOLD
- DATA_GAP

Author Action Required is independently shown as `YES` or `NO` with a reason.

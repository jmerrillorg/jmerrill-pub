# ECR Governance and Component Map

## Standard

JM1 Enterprise Communication Standard v1.0.

Supported output profiles:

- `EMAIL_HTML`
- `EMAIL_TEXT`

Future profiles:

- `LETTER`
- `PORTAL_NOTICE`
- `SMS_SUMMARY`
- `REPORT`

## Enterprise Components

- Compact enterprise brand header.
- Stage-specific content title.
- Optional subtitle/title name.
- Greeting.
- Why you are receiving this.
- What has been completed.
- What's attached.
- What we need from you.
- How to respond.
- Optional Author Operating Center access.
- What happens next.
- Support.
- Governed brand signature.

## Prohibited Output

- Oversized plain-text company name as message H1.
- Invented closings.
- Workflow-specific HTML.
- Unapproved colors.
- Internal artifacts.
- Mandatory portal language.
- Response-clock language before authority exists.

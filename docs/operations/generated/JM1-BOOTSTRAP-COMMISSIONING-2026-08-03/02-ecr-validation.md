# ECR Validation

## Status

Enterprise Communication Renderer: PRODUCTION.

## Required Components

- Brand Header.
- Hero.
- Greeting.
- Purpose.
- Summary.
- Attachments.
- Action Required.
- Timeline.
- Support.
- Signature.
- Footer.

## Renderer Controls

- ECR fails closed without JM1 Governed Bootstrap render authority.
- Brand names cannot render as message H1.
- Invented closings are prohibited.
- Internal artifacts are prohibited.
- Mandatory portal language is prohibited.
- Response-clock language requires authority.
- HTML and plain text are both required.

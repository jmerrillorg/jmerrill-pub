# Reviewer Surfacing Requirement

Last verified: 2026-08-10T14:04:00Z

Before INTERNAL REVIEW, the normal operating surface must give Jackie:

- title;
- review type;
- artifact name;
- visual/download/open access;
- version or checksum;
- the decision to make;
- decision options.

A file merely existing somewhere is insufficient.

Jackie must not have to:

- search GitHub;
- search generated evidence directories;
- inspect execution logs;
- reconstruct a SharePoint path;
- ask Cody where the file is.

The durable pattern is:

Artifact becomes review-ready -> governed title workspace contains artifact -> operating surface points Jackie directly to it -> optional notification may alert Jackie.

Email alone is not the fix and is not the system of record.

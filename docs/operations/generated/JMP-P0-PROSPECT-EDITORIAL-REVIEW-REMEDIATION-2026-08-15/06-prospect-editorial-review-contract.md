# Prospect Editorial Review Contract

Last verified: 2026-08-15

Evidence source: `lib/server/prospect-editorial-review-policy.ts`

Required prospect content:

- Editorial Review summary
- Primary publishing package recommendation
- Backup recommendation when applicable
- Recommended imprint when available
- Exactly three title suggestions for `Untitled`
- Package-selection CTA

Forbidden prospect content:

- Active-author stage approval language
- Developmental approval language
- Current publishing-stage approval language
- Local file links

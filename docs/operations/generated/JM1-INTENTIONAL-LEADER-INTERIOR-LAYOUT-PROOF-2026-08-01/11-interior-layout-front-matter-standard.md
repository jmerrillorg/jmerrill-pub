# JM1 Publishing Interior Layout Front Matter Standard

Effective: 2026-08-01

Authority: Jackie executive publishing ruling

## Rule

For author-review Interior Layout proofs, the following front matter is required and production-generated unless a title has an approved alternate standard:

- title page;
- copyright page;
- automatically generated table of contents;
- complete body manuscript.

Optional material must be included only when approved and available:

- dedication;
- acknowledgments;
- foreword;
- preface;
- biography;
- marketing pages;
- supplemental back matter.

Absence of optional material does not block author-review proof release.

If ISBN is assigned, include it. If ISBN is pending, leave it blank or mark it pending according to J Merrill Publishing's copyright-page standard. ISBN pending does not block author-review proof release.

ISBN assignment occurs later at the Production Metadata Gate, after title, author, imprint, edition, format, rights holder, and publication intent are confirmed. Final distribution-ready files require format-specific ISBN assignment before certification.

## The Intentional Leader Application

The Intentional Leader used this standard to generate:

- title page;
- copyright page with J Merrill Publishing imprint;
- generated table of contents;
- 388-page body proof.

The resulting author-review PDF contains 393 pages and passed visual QA.

## Future Guard

Interior Layout release eligibility must fail if title page, copyright page, TOC, complete body manuscript, manifest page count, or visual QA is missing. It must not fail merely because optional author content is not present.

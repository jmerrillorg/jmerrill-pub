# Format, ISBN, and Disclaimer Policy

## Format Authority

The publishing agreement or approved title-format decision controls:

- Paperback
- Hardcover
- eBook
- Audiobook
- Large Print
- Accessible Edition
- Other approved formats

For each title:

- Contracted format: render ISBN field.
- Uncontracted format: remove ISBN field and label.

Do not leave blank ISBN labels in active title output.

## ISBN Boundary

Author-review stage: ISBN assignment is optional and nonblocking.

Final distribution stage: ISBN assignment is required for each active format.

## Title-Format Decision Object

The canonical title-format record must include:

- Title ID
- Intake reference
- Contract/package
- Approved formats
- Format status
- ISBN by format
- ISBN assignment status
- Trim size
- Imprint
- Edition
- Publication date
- Distribution channel
- Large-print status
- Accessible-edition status

## Disclaimer Library

The full disclaimer library remains internal. For each active title, production must select the appropriate disclaimer, approve any title-specific modification, insert only the approved disclaimer, and remove all unused disclaimer options and labels.

Required result:

Selected disclaimer blocks: 1 OR APPROVED COMBINATION
Unused disclaimer blocks: 0
Internal disclaimer headings exposed: 0

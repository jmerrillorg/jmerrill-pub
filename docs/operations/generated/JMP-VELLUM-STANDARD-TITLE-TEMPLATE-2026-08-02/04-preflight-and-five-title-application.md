# Preflight and Five-Title Application

## Vellum Assembly Preflight

Before generating an author-review proof, verify:

| Check | Required result |
| --- | --- |
| Correct Vellum master | PASS |
| Correct title metadata | PASS |
| Correct manuscript | PASS |
| Active formats | PASS |
| Unused ISBN fields removed | PASS |
| Selected disclaimer | PASS |
| Sample content removed | PASS |
| Unused sections removed | PASS |
| TOC source headings valid | PASS |

| Back matter complete | PASS |

- `MISSING_REQUIRED_TITLE_METADATA`

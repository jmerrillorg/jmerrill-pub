# Block 08 And Block 09 Handoff

Last Verified: 2026-08-26

## Block 08

Block 08 receives `PRIMARY_RELEASE_LIVE` only after required live endpoints are verified.

Unverified buy links are not included in the handoff.

## Block 09

Block 09 receives `BLOCK09_DISTRIBUTION_RECORD_HANDOFF_READY` with:

- external IDs;
- channel IDs;
- live URLs;
- format and territory availability;
- live timestamps;
- pricing;
- distribution state;
- release health.

No royalty processing or long-term title-management activity is executed in Block 07.

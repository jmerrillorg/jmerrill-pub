# Final Certification and Block 06 Handoff

## Final Production Certification Gate

The runtime requires all of the following before `PUBLICATION_ASSETS_READY`:

- `SCOPE_LOCK_COMPLETE`
- `ALL_REQUIRED_WORKSTREAMS_CERTIFIED`
- `ALL_REQUIRED_AUTHOR_APPROVALS_COMPLETE`
- `ALL_REQUIRED_TECHNICAL_VALIDATION_PASS`
- `ALL_FINAL_ARTIFACTS_IDENTIFIED`
- `ALL_CHECKSUMS_VERIFIED`
- `REQUIRED_IDENTIFIERS_RESOLVED`
- `PUBLICATION_METADATA_READY`
- `ACCESSIBILITY_SATISFIED_OR_GOVERNED_DEPENDENCY`
- `NO_UNRESOLVED_PRODUCTION_CORRECTION`
- `CROSS_FORMAT_SYNC_PASS`
- `HANDOFF_PACKAGE_COMPLETE`

Final probe result: `PUBLICATION_ASSETS_READY`.

## Block 06 Handoff

Runtime handoff package: `BLOCK06_PUBLICATION_ASSET_HANDOFF`.

The package includes:

- Title.
- Author.
- Imprint.
- Package / formats.
- Final artifact IDs.
- Checksums.
- Identifiers where applicable.
- Publication metadata.
- Specification profile / version.
- Author approvals.
- Technical validation evidence.
- Accessibility status.
- Rights / permissions.
- Governed dependencies.
- Physical proof status.
- Certification timestamp.

Block 06 does not need to reconstruct Production from folders or email.

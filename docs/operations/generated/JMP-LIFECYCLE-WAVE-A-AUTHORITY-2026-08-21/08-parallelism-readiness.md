# 08 - Parallelism and Readiness

The registry canonizes:

Parallelize preparation. Serialize irreversible gates.

Allowed preparatory work includes cover concept, metadata drafting, marketing preparation, and distribution preparation. The validator permits those activities while the title remains in Editorial Production.

The validator rejects Full Wrap finalization without final page count/spine/specification evidence represented by the final interior dependency.

Readiness concepts remain distinct. Examples:

- EDITORIAL_PRODUCTION_READY
- BOOK_PRODUCTION_READY
- METADATA_READY
- DISTRIBUTION_READY
- ROYALTY_PAYOUT_READY
- FINAL_DELIVERY_PAYMENT_READY

Wave A defines the contract only; it does not add Dataverse fields.

# Canonical Authority Consumption Spec

`CANONICAL_CURRENT_TITLE`, `CANONICAL_PUBLISHED_TITLE`, and `CANONICAL_EDITION` may project current lifecycle authority. `DUPLICATE_RECORD`, `LEGACY_TITLE_RECORD`, `PLACEHOLDER`, `HISTORICAL_VERSION`, `ORPHAN`, and `REQUIRES_RECONCILIATION` remain visible as descriptive records but cannot establish current lifecycle stage, substage, or movement authority. Unresolved cases return `RECONCILIATION_REQUIRED`.

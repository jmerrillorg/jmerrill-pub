# Style-Guide Inheritance

The primary style-guide determination begins at Editorial Review and carries
downstream unless explicitly overridden by the Publisher:

```text
Editorial Review
  -> Developmental
  -> Line
  -> Copy
  -> Proof
```

The synchronized canon now directs downstream stages to use the upstream
Editorial Review style-guide determination where it exists. Stages should not
independently reinvent the style guide when a governed upstream decision is
available.

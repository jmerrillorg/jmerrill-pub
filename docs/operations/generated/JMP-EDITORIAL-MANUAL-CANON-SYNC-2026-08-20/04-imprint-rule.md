# Imprint Rule

Canonical rule:

```text
IF confirmed imprint exists:
    use confirmed imprint
ELSE:
    determine/use suggested imprint
    continue Editorial Review
```

Do not create `BLOCKED`, `WAITING_ON_JACKIE`, or `WAITING_ON_AUTHOR` solely
because the imprint is not confirmed.

If the suggested imprint is JM Signature, Editorial Review still proceeds, but
official JM Signature assignment requires Publisher approval. The synchronized
manual canon uses the equivalent state:
`JM_SIGNATURE_RECOMMENDED_PENDING_PUBLISHER_APPROVAL`.

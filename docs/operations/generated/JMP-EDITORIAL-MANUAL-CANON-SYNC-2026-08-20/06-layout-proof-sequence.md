# Layout / Proof Sequence

Canonical sequence:

```text
Copy
  -> Author Approval
  -> Layout / Typesetting
  -> Proof
  -> Final Author Approval
  -> Production Finalization
```

Proofreading is post-layout verification, not another editorial rewrite.

Proof must be capable of checking:

- page breaks;
- running heads;
- folios;
- TOC pagination;
- stranded headings;
- tables/layout;
- layout-introduced errors;
- final mechanical defects.

The exact post-layout Proof artifact requires Final Author Approval before
Production Finalization.

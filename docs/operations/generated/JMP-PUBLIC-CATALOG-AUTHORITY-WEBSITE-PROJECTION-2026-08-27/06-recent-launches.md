# Recent Launches

Last Verified: 2026-08-27T22:56:00-04:00

Recent and future launches now share the same public gate:

1. distribution/live evidence is recorded;
2. a Dataverse public catalog record is available;
3. `/books/{canonical-title-slug}` is reachable;
4. required `/authors/{canonical-author-slug}` page is reachable;
5. `PUBLIC_CATALOG_PROJECTION` evidence is attached before post-publication stewardship.

This prevents a title from closing release merely because a retailer listing exists.

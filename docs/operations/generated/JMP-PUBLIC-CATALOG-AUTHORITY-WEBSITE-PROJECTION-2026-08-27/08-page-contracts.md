Required public fields:

- title;
- canonical slug;
- public author display name or governed anonymous/hidden treatment;
- author page link when profile is public;
- imprint;
- genre;
- formats;
- ISBNs where available;
- cover URL or governed fallback;
- purchase/listing links as evidence;
- SEO canonical URL;
- JSON-LD structured data.

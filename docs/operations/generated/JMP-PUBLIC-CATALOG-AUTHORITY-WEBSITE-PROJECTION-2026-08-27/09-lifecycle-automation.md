# Lifecycle Automation

Last Verified: 2026-08-27T22:56:00-04:00

Lifecycle validation now requires a `PUBLIC_CATALOG_PROJECTION` artifact when moving from `DISTRIBUTION_RELEASE` to `POST_PUBLICATION`.

This binds `TITLE_LIVE_AND_VERIFIED` to JMP-controlled public pages and prevents Block 09 title management from treating a title as fully live when the JMP public page is missing.

Retailer presence may support the evidence package, but it cannot replace the JMP public page check.

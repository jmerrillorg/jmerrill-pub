# Package Acceptance Trigger

## Canonical Event

Conceptual event: `PACKAGE_ACCEPTED`.

## Accepted Channels

- Governed author email response.
- Author Workspace choice.
- Publisher-recorded phone or in-person decision.
- Other governed author-decision path.

## Acceptance Semantics

Unambiguous package acceptance triggers offer calculation. Vague enthusiasm does not.

Examples:

- `Yes` when only one active package recommendation is selectable: accepted.
- `I would like to move forward with Professional`: accepted.
- `Sounds interesting`: not accepted.
- Ambiguous yes when multiple selectable packages were presented: clarification required.

## Activation State

Automatic live send is not activated in this PR. The package acceptance trigger remains integration work.

# Automatic Response Flow

## Target Flow

Editorial Review -> Package Recommendation -> Author says YES -> `PACKAGE_ACCEPTED` -> Offer Calculation -> Benefits Applied -> Payment Options Generated -> Author Selects Payment Option -> Pricing Snapshot Locked -> Agreement/Addendum/Payment arrangement.

## New Author

If no referral selection is required, the response can present adjusted principal and Full / 2 / 4 / 8 Pay options without manual arithmetic.

## Returning Author

The returning-author benefit is automatic and should be stated plainly.

## Referral Credits

If available credits exist, the author must choose how much to apply. Invalid choices above the 50 percent combined cap must not be offered.

## Activation State

Automatic response activation is not enabled in this PR. Existing email and Workspace response paths must be wired in a later bounded PR after Founder review.

# 21 - Phase 1 Decision Packet

- Ten-stage lifecycle remains founder-approved North Star.
- Three dimensions must remain separate: prospect/commercial, title, author relationship.
- Human decisions may arrive by email, portal, phone/verbal, or other channel and should be recorded without forcing repeat.
- Stripe remains payment authority; Dataverse/JMP remains workflow authority.

## Can Be Resolved from Current Architecture

- J0-J8 should be adapted, not deleted, into `JMP_PUBLISHING_LIFECYCLE_v1.0`.
- Package Engine and Notification Engine should consume one package policy adapter.
- Operating Center should become a registry-backed read model before broad runtime migration.
- Line runtime should remain held for affected titles until the prior audit defect is repaired.

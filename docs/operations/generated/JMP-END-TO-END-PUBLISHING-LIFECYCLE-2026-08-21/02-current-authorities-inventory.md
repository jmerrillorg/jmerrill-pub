## Canon vs Runtime vs Dataverse vs UI

Canon says there should be one lifecycle authority with three state dimensions. Runtime currently has multiple stage authorities. Dataverse stores partial source truth across title, asset, intake, opportunity, editorial stage/gate/artifact, production project/task, and execution-log tables. UI displays an Operating Center projection that is useful but not canonical.

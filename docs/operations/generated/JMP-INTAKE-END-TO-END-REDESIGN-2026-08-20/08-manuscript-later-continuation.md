# Manuscript-Later Continuation

Implemented foundation:

- `/join` accepts `manuscriptSubmissionChoice=later`.
- A durable inquiry can exist without manuscript evidence.
- Missing manuscript no longer triggers Editorial Review orchestration failure.
- Waiting owner is modeled as `Prospect`.

Not yet implemented:

- Secure continuation token/link.
- Upload-later endpoint.
- Token expiry/renewal.
- Limited prospect status page.

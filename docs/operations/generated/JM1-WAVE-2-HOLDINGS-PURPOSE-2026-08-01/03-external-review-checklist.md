# Holdings Counsel And Accounting External-Review Checklist

Status: DISCOVERY COMPLETE - COUNSEL / ACCOUNTING REVIEW PENDING
Created: 2026-08-01

## Purpose Structure To Preserve

Primary purpose: coordinate enterprise-level ownership, stewardship, shared services, brand administration, intellectual-property strategy, and inter-entity operating standards across the J Merrill ecosystem.

Secondary purpose: evaluate whether a formal holding or management-services structure improves governance clarity, liability separation, tax/accounting treatment, and shared-service operations.

Future optional purposes: future banking, capitalization, intercompany service agreements, intellectual-property holding, brand stewardship, and shared administration, only after professional review and Jackie ratification.

## External Review Checklist

| Review area | Question for counsel/accounting |
| --- | --- |
| Legal entity suitability | Is a holdings or management-services entity appropriate for the intended JM1 structure? |
| Ownership chain | What ownership chain should exist across current and contemplated entities? |
| Trust interaction | Should any trust be involved, and if so under what legal/tax constraints? |
| Tax classification | What entity tax classification and filing posture is recommended? |
| Accounting consolidation | How should inter-entity activity be consolidated or reported? |
| Intercompany agreements | What agreements are required before any shared-service or ownership function begins? |
| Liability separation | What structure best preserves liability separation between entities and activities? |
| Intellectual-property ownership | Where should trademarks, copyrights, manuscripts, templates, and platform assets reside? |
| Banking and capitalization | What banking and capitalization steps are required and in what sequence? |
| Future optional functions | Which optional functions should remain prohibited until separately approved? |
| Implementation sequence | What step-by-step legal/accounting implementation path is safest? |
| Prohibited premature transfers | What transfers, assignments, or funding actions must not occur before professional clearance? |

## Non-Implementation Boundary

This checklist does not authorize entity formation, asset transfer, ownership transfer, bank-account opening, capitalization, tax election, Business Central changes, or contract assignment.
